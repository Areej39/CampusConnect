# CampusConnect

A full-stack university event and sports-day management system.

## Features

- Student authentication
- Admin authentication
- Event management
- Event registration
- Seat management
- Payment reference submission
- Registration approval/rejection
- Search, filtering and pagination
- Admin dashboard

## Tech Stack

Frontend:
- React
- Vite
- Tailwind CSS
- React Router

Backend:
- Node.js
- Express
- MongoDB
- Mongoose
- JWT
- Zod
